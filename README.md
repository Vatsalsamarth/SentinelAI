# SentinelAI — Real-Time Fraud Detection Platform

SentinelAI is an end-to-end machine learning system for detecting fraudulent financial transactions.

## Features

- Fraud Detection using Machine Learning
- Feature Engineering Pipeline
- Explainable AI with SHAP
- FastAPI REST API
- Streamlit Dashboard
- MLflow Experiment Tracking
- Docker Deployment

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- LightGBM
- SHAP
- FastAPI
- Streamlit
- MLflow
- Docker
